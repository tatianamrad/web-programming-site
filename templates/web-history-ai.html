History of the World Wide Web

Evolution of the Global Information Space

History of the Internet History of the Web

The World Wide Web is the space inside the internet where people actually browse media and interact with it[cite: 1]. It was first invented for the simplification of sharing documents and links between people, and it was then transformed into something any human can use regardless of language barriers, age, etc[cite: 1]. The web has shaped the modern person’s daily life by turning the Internet into the social media platforms, websites, and online pages he browses through every day[cite: 1].

March 1989: Tim Berners-Lee’s Proposal at CERN

Sir Tim Berners-Lee, a British scientist, wrote a document titled “Information Management: A Proposal” at CERN, which described an information management system using hypertext links[cite: 1]. The web was originally created for information sharing between academics in universities and institutes around the globe, regardless of computer setup[cite: 1].

December 1990: First Web Technologies Go Live

Berners-Lee created the URL system, HTTP (Hypertext Transfer Protocol), and HTML (HyperText Markup Language)[cite: 1]. On a NeXT computer, he created the first browser/editor program and launched the first web server (info.cern.ch)[cite: 1]. It demonstrated how documents might be obtained via clickable links across many computers, which transformed theoretical network architecture into useful software[cite: 1].

April 30, 1993: CERN Releases Web Software into Public Domain

CERN released the primary source code of the World Wide Web software into the public domain, making it royalty-free[cite: 1]. CERN prevented proprietary lock-in and sparked global web software development by making the code open for anyone to use, modify, or expand without paying a license fee[cite: 1].

1993: Release of NCSA Mosaic

The Mosaic web browser was developed by Marc Andreessen and Eric Bina at UIUC's National Center for Supercomputing Applications (NCSA)[cite: 1]. The Web became an accessible and user-friendly platform when Mosaic became the first graphical browser to show images in line with text on personal computers[cite: 1].

October 1994: Foundation of the W3C

Tim Berners-Lee founded the World Wide Web Consortium (W3C) at MIT in collaboration with DARPA and the European Commission[cite: 1]. The W3C acted as a neutral organization to create open standards, such as HTML specifications, as commercial browsers started adding contradictory, non-standard features[cite: 1].

December 1996: CSS Level 1 Recommendation

In December of 1996, the W3C officially published the specification for Cascading Style Sheets (CSS Level 1)[cite: 1]. It cleanly separated a webpage's structural content (HTML) from its visual design (CSS), enabling websites to be easily maintained, lightweight, and adaptable across screens and devices[cite: 1].

2004: Web 2.0 is Launched

With the introduction of sites like Facebook, Youtube, and early blogging services, Tim O'Reilly and Dale Dougherty organized the first Web 2.0 Conference, which caused a shift in the way people used the Web[cite: 1]. This is significant because Web 1.0 was read-only, where a few webmasters published content for users to read, while Web 2.0 signaled the transition to a read-write powered by user-generated content, web APIs, and web-based applications[cite: 1].
