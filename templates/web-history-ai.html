Evolution of the Global Information Space

The World Wide Web is the space inside the internet where people actually browse media and interact with it. It was first invented for the simplification of sharing documents and links between people, and it was then transformed into something any human can use regardless of language barriers, age, etc. The web has shaped the modern person’s daily life by turning the Internet into the social media platforms, websites, and online pages he browses through every day.

March 1989: Tim Berners-Lee’s Proposal at CERN

Sir Tim Berners-Lee, a British scientist, wrote a document titled “Information Management: A Proposal” at CERN, which described an information management system using hypertext links. The web was originally created for information sharing between academics in universities and institutes around the globe, regardless of computer setup.

December 1990: First Web Technologies Go Live

Berners-Lee created the URL system, HTTP (Hypertext Transfer Protocol), and HTML (HyperText Markup Language). On a NeXT computer, he created the first browser/editor program and launched the first web server (info.cern.ch). It demonstrated how documents might be obtained via clickable links across many computers, which transformed theoretical network architecture into useful software.

April 30, 1993: CERN Releases Web Software into Public Domain

CERN released the primary source code of the World Wide Web software into the public domain, making it royalty-free. CERN prevented proprietary lock-in and sparked global web software development by making the code open for anyone to use, modify, or expand without paying a license fee.

1993: Release of NCSA Mosaic

The Mosaic web browser was developed by Marc Andreessen and Eric Bina at UIUC's National Center for Supercomputing Applications (NCSA). The Web became an accessible and user-friendly platform when Mosaic became the first graphical browser to show images in line with text on personal computers.

October 1994: Foundation of the W3C

Tim Berners-Lee founded the World Wide Web Consortium (W3C) at MIT in collaboration with DARPA and the European Commission. The W3C acted as a neutral organization to create open standards, such as HTML specifications, as commercial browsers started adding contradictory, non-standard features.

December 1996: CSS Level 1 Recommendation

In December of 1996, the W3C officially published the specification for Cascading Style Sheets (CSS Level 1). It cleanly separated a webpage's structural content (HTML) from its visual design (CSS), enabling websites to be easily maintained, lightweight, and adaptable across screens and devices.

2004: Web 2.0 is Launched

With the introduction of sites like Facebook, Youtube, and early blogging services, Tim O'Reilly and Dale Dougherty organized the first Web 2.0 Conference, which caused a shift in the way people used the Web. This is significant because Web 1.0 was read-only, where a few webmasters published content for users to read, while Web 2.0 signaled the transition to a read-write powered by user-generated content, web APIs, and web-based applications.

December 1995–Present: Evolution of JavaScript and Client-Side Scripting

Created by Brendan Eich in December 1995, JavaScript transformed static web pages into interactive software applications [cite: Mozilla Developer Network, 2023]. Over time, with the introduction of standardizations like ECMAScript 6 (ES6) in 2015 and modern frontend frameworks, JavaScript became the essential core language of web development, empowering real-time updates, single-page applications, and responsive desktop-like user interfaces within the browser.

October 2014: Official W3C Recommendation of HTML5

In October 2014, the W3C officially published the HTML5 specification as a formal recommendation [cite: World Wide Web Consortium, 2014]. HTML5 standardized modern web capabilities by introducing native audio and video support (audio and video tags), canvas graphics, semantic tags (article, section, header tags), and web storage APIs. This reduced reliance on third-party plugins like Adobe Flash and unified mobile and desktop web standards across all browsers.

2018–Present: The "HTTPS Everywhere" Movement and Universal Web Encryption

Driven by initiatives like Let's Encrypt (launched in 2016) and major browser security policies enforcement starting around 2018, HTTPS (HTTP over TLS/SSL) became the baseline standard for web browsing [cite: Let's Encrypt, 2016]. Browsers began flagging traditional HTTP connections as "Not Secure," ensuring that end-to-end data encryption, session integrity, and user privacy were universally integrated across nearly every website on the Internet.
